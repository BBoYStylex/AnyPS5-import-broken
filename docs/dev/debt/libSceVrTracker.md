# libSceVrTracker technical debt

### Silent stubs

- [libSceVrTracker](../../../core/libs/prx/libSceVrTracker/Export.cpp) implements only the uninitialized tracker: `sceVrTrackerInit` throws, so the tracker never initializes, and `sceVrTrackerGetTime`, `sceVrTrackerGpuSubmit` and `sceVrTrackerGpuWait` return `NOT_INIT` (`0x81260801`) for every argument and write nothing

- [sceVrTrackerCpuProcess, sceVrTrackerGetResult and sceVrTrackerInit](../../../core/libs/prx/libSceVrTracker/Export.cpp) (libSceVrTracker) - names and NIDs are present in the [PS5 3.20 export inventory](https://github.com/DNNDHH/PS5-3.20_Libs/blob/b2a77c09cd71c01f34c790cfbe98c751a13262ad/libSceVrTracker.c); their prototypes, given for the PS4 by [Orbital](https://github.com/AlexAltea/orbital/blob/cc408367da6a6ebbf5ac1ac559fefeadc73b2831/tools/ida/db_types.json#L2471-L2484), are not verified on a PS5. The declarations have no parameters solely to resolve known imports; this is not an ABI claim and callers must not call them until signatures are verified
