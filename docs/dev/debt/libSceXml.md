The 198 pending exports this library declares are the console's `libSceXml.sprx`
exports that no built library provides, so a title importing one of their NIDs did not
start. Their names come from the public [PS5 3.20 export inventory]
(https://github.com/DNNDHH/PS5-3.20_Libs/blob/b2a77c09cd71c01f34c790cfbe98c751a13262ad/libSceXml.c),
whose generator emits a runtime `sprx_dlsym` trampoline per symbol and therefore lists
functions only: every `@object` symbol the type-aware generator of the public PS5 payload
SDK's [stub tables](https://github.com/ps5-payload-dev/sdk/blob/a7685ce8e97ce1f8a4f38253a41d54241c9124f1/sce_stubs)
emits is absent from that list. Every name is also listed in the
[NID name database](https://github.com/zecoxao/sce_symbols/blob/main/aerolib.csv) at `6bfb2a9`,
and each name hashes to the NID recorded there. No PS5 source declares their prototype,
so each declaration uses the no-parameter unknown-signature convention and throws through
`NotImplemented_nid_no_patch`. The entries below name the symbols they cover.
