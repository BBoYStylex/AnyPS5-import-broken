# libSceOpusCeltDec technical debt

### Functional

- [libSceOpusCeltDec](../../../core/libs/prx/libSceOpusCeltDec/Export.cpp) uses the [libSceOpusDec decoder](../../../core/libs/prx/libSceOpusDec/src/Decoder.cpp) and accepts only CELT-only packets, TOC configurations 16-31, the split that [public PS5 decoder research](https://github.com/blackbearreloaded/ps5-hardware-audio-decoding/blob/26be5a12f92b2cdc67f8a9e082fd69ae0e9a35a2/docs/DECODING.md#production-opus-dispatch) gives for this module. Packets of other configurations throw; the console's result for them is unknown. The signatures follow [ProsperoRadio](https://github.com/blackbearreloaded/ProsperoRadio/blob/2c4029c3a8f43e9e1dfef98374d94d99b14d745d/src/opus_decoder.cpp). `sceOpusCeltDecGetSize` returns 640 bytes, the size measured for libSceOpusDec; the CELT module's size is not measured, and the host keeps decoder state outside the guest buffer. The limits of [libSceOpusDec](libSceOpusDec.md) apply: 48000 Hz mono and stereo only, no packet loss concealment, console PCM equivalence and error codes unverified. PPSA99001 opens this decoder only as a fallback when libSceOpusDec reports a retryable error for a CELT packet, which libSceOpusDec here never returns, so the title does not reach it
