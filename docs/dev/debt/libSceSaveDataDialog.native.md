# libSceSaveDataDialog.native technical debt

### Silent stubs

- [libSceSaveDataDialog.native](../../../core/libs/prx/libSceSaveDataDialog.native/Export.cpp) uses automatic responses unless `APS5_SAVEDATA_DIALOG_UI=1`: selection modes finish with the first nonempty directory and button 1, and progress stays running until closed. This remains the default pending title validation of the interactive path.

### Functional

- [Interactive save dialogs](../../../core/libs/prx/libSceSaveDataDialog.native/DialogWindow.cpp) support list mode (1) and progress mode (5) on Windows and Linux with `APS5_SAVEDATA_DIALOG_UI=1`. A separate native window lists the caller's nonempty directory names; save and delete choices require confirmation, load choices return on acceptance, and cancel returns result 1 with button 0 and an empty directory. Percentage progress parameters copy the caller's message; system message type 2 uses a restore message when none is supplied. Progress has no user-cancel control and remains running at 100% until the caller closes it. Only keyboard and mouse input is handled. The library chooses a directory; the caller still performs the operation. Linux uses a separate X11 connection and event loop; Wayland requires XWayland. Save and delete confirmation appears in the same window with No focused initially. An unavailable display throws before opening completes. Linux uses an X11 Unicode bitmap font when available, with `fixed` as the fallback. Font coverage limits displayed glyphs; characters above U+FFFF display a replacement glyph, while results preserve the original UTF-8. Screen-reader integration and a native Wayland backend are not implemented. Linux was built and tested under Debian 12 with GCC 12 and Xvfb; a title and an XWayland desktop remain untested.
- [Interactive dialog parameters](../../../core/libs/prx/libSceSaveDataDialog.native/Export.cpp) use the existing ABI prefixes for the directory list and result. Extended list data, new-item descriptors, slot metadata, icons, focus options and controller navigation are not implemented. Non-null animation, user/system-message, error-code, option or wizard parameters, modes other than 1 and 5, and result metadata pointers throw on the interactive path. The 0x30-byte progress parameter layout (message pointer at +8, system message type at +16), result 1 for user cancellation, button 0 for cancellation and display types 1/2/3 for save/load/delete follow [shadPS4](https://github.com/shadps4-emu/shadPS4/blob/main/src/core/libraries/save_data/dialog/savedatadialog_ui.h) and its [common-dialog result enum](https://github.com/shadps4-emu/shadPS4/blob/main/src/core/libraries/system/commondialog.h), not PS5 hardware measurements. No title establishes the complete PS5 layouts, timing or selection behavior.
