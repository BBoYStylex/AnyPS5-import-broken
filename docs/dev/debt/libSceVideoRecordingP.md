# libSceVideoRecordingP technical debt

### Unknown function info

- [sceVideoRecordingOpen, sceVideoRecordingStart, sceVideoRecordingStop, sceVideoRecordingClose, sceVideoRecordingGetStatus, sceVideoRecordingQueryMemSize](../../../core/libs/prx/libSceVideoRecordingP/Export.cpp) (libSceVideoRecording) - the 16-byte `{Size, RingSec, Format}` parameter, the `None = 0`, `Running = 1`, `Paused = 2` statuses, the `Mp4AvcAac = 0` and `WebmVp9Opus = 1` containers, the 1023-byte path limit and the 3600-second ring limit are from the PS5 GDK bindings in [SharpProspero](https://github.com/SvenGDK/SharpProspero/blob/main/src/SharpProspero/Interop/Video/VideoRecording.cs), whose declarations match the ones here one for one; that the console library behaves as that wrapper describes is not read from the console's binary, and the PS4 `libSceVideoRecording` in [OpenOrbis](https://github.com/OpenOrbis/OpenOrbis-PS4-Toolchain/blob/master/include/orbis/VideoRecording.h) declares the same names without types. They throw because no title in this tree is known to call this library, so reporting success would record nothing
- [sceVideoRecordingQueryParam](../../../core/libs/prx/libSceVideoRecordingP/Export.cpp) (libSceVideoRecording) is the call that binding makes before opening, to fill the parameter with the service's own defaults; it is added as a throwing stub by [#6293](https://github.com/boykopovar/AnyPS5/pull/6293), so a title that fills its parameter that way still stops there

### Functional

- [sceVideoRecordingGetInfo, sceVideoRecordingSetInfo](../../../core/libs/prx/libSceVideoRecordingP/Export.cpp) (libSceVideoRecording) keep every value the caller sets in a map keyed by its info id, and `sceVideoRecordingGetInfo` refuses a buffer smaller than the value and an id that was never set. The ids, their types and which of them the console keeps across sessions are not known. The map is not cleared by `sceVideoRecordingClose`, which the console's behaviour for it is not measured
