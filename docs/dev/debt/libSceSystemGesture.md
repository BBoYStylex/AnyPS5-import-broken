# libSceSystemGesture technical debt

### Unknown function info

- [sceSystemGestureGetPrimitiveTouchEventByPrimitiveID, sceSystemGestureGetTouchEventByEventID, sceSystemGestureGetTouchRecognizerInformation](../../../core/libs/prx/libSceSystemGesture/Export.cpp) (libSceSystemGesture) - signatures follow [KytyPS5](https://github.com/KytyPS5/KytyPS5/blob/9e41d8320a2774b303fbad344c2347e8d0292e83/src/libs/libSystemService.cpp), not a console measurement. With no touch input no primitive or event ID exists, so both lookups return `0x80D10005`, the not-found code `GetPrimitiveTouchEventByIndex` returns here (KytyPS5: `EVENT_DATA_NOT_FOUND`, `0x80890005`), and leave the event untouched (KytyPS5 clears it). `sceSystemGestureCreateTouchRecognizer` stores the gesture type and rectangle in the caller's recognizer, `UpdateTouchRecognizerRectangle` replaces the rectangle and `GetTouchRecognizerInformation` returns both with `updated_time` 0 (KytyPS5 returns all zeros). A null rectangle to Create returns `INVALID_ARGUMENT`, as in UpdateTouchRecognizerRectangle. A recognizer Create did not initialize throws in GetTouchRecognizerInformation and UpdateTouchRecognizerRectangle; the console's answer is unknown

### Silent stubs

- [System gesture recognizers](../../../core/libs/prx/libSceSystemGesture/Export.cpp) (libSceSystemGesture) - `sceSystemGestureGetPrimitiveTouchEvents`, `GetPrimitiveTouchEventsCount`, `GetTouchEvents`, `GetPrimitiveTouchEventByIndex` and the recognizer append, remove, reset and update calls report that no touch input exists, so a title never receives a gesture event. A recognizer keeps only its type and rectangle. Handle and pointer arguments are still checked. Error codes follow the 0x80D1 values main already uses in this file; KytyPS5 uses 0x8089 (INVALID_ARGUMENT 0x80890001, INVALID_HANDLE 0x80890006), and which one the console returns is not verified
