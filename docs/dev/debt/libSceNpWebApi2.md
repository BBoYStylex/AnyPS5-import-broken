# libSceNpWebApi2 technical debt

### Unknown function info

- [sceNpWebApi2PushEventAbortHandle](../../../core/libs/prx/libSceNpWebApi2/Export.cpp) (libSceNpWebApi2, NID `1OLgvahaSco`) marks a push event handle as aborted, after which `sceNpWebApi2PushEventCreateFilter` on it returns `ABORTED` (`0x80553409`); callbacks already registered are left as they are. `sceNpWebApi2PushEventCreateHandle`, `sceNpWebApi2PushEventDeleteHandle` and `sceNpWebApi2PushEventCreateFilter` keep handles per library context, and `sceNpWebApi2Terminate` drops them. The signature, check order and codes for an unknown context (`LIB_CONTEXT_NOT_FOUND`, `0x80553404`) or handle (`HANDLE_NOT_FOUND`, `0x8055340D`) follow [shadPS4](https://github.com/shadps4-emu/shadPS4/blob/e0a466753a1aacbc8db8253be685bf7ab4d9daae/src/core/libraries/np/np_web_api2/np_web_api2_internal.cpp#L112-L132) (PS4) and are unverified on PS5; handle timeouts and `CreateFilter` argument checks are not modeled. PPSA01736 imports it.
- [sceNpWebApi2GetMemoryPoolStats](../../../core/libs/prx/libSceNpWebApi2/Export.cpp) (libSceNpWebApi2) - imported by PPSA21703's Unity PSN plugin. The signature `(int libCtxId, stats*)` and the layout of the Http2 statistics above (measured on a PS5 for Http2, Ssl and Net) are assumed for this library, not measured. The pool size is the one given to `sceNpWebApi2Initialize`, and the peak and current use are 0. The error codes are unknown, so a null output or an unknown context throws
- [sceNpWebApi2PushEventSetHandleTimeout](../../../core/libs/prx/libSceNpWebApi2/Export.cpp) (libSceNpWebApi2) - imported by PPSA01317, which fails to load without it. The signature `(int libCtxId, int handleId, uint32_t timeout)` follows `sceNpWebApiSetHandleTimeout` of the PS4 libSceNpWebApi in [shadPS4](https://github.com/shadps4-emu/shadPS4/blob/main/src/core/libraries/np/np_web_api.cpp) and is unverified on the PS5. An unknown library context throws, as in `sceNpWebApi2GetMemoryPoolStats`, since its error code is unknown. The handle is not checked, as push event handles are not tracked (`sceNpWebApi2PushEventDeleteHandle` accepts any handle), and the timeout is not kept, as nothing waits on a handle offline
